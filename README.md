# League of Auxilia UI

NeoShowcaseでのRuntime登録・環境変数・Docker検証は [デプロイ設定](deploy/README.md) を参照してください。

1対1 MOBAのエントランス、マッチング、ゲームシーン。React / TypeScript / Vite。

## 起動

別ターミナルで `../League of Auxilia-server` の `go run .` を起動した後、このディレクトリで実行します。

```sh
npm install
npm run dev
```

表示されたURLを開き、名前入力 → キャラ・スペル選択 → マッチング開始の順に操作します。
開発時はViteが `/api` と `/ws` を `127.0.0.1:8080` へ転送します。

2人の動作確認には通常ブラウザーとプライベートウィンドウ、または別ブラウザーを使ってください。同一Cookieを共有する複数タブは同じプレイヤーとして同期され、自分同士ではマッチングしません。

## 実装範囲

- 4キャラ選択、異なるD/Fスペル、名前1〜16文字、BGM/SE音量保存・再生。
- 先着順の待機列、キャンセル、ランダムなblue/red割り当て。
- 両者の名前・キャラ・スペル・画像ロード状況、30秒のロード期限、3秒カウントダウン。
- カウントダウン後に戦場へ遷移。マップ、施設、廃墟、4キャラ、共有視界を描画します。
- サーバー判定による移動・経路探索・通常攻撃・死亡・復活・リコール・基本報酬。受信した位置を補間して描画します。
- ミニマップ、カメラ、対象情報、HP・マナ・ゴールドなどのHUD。
- 4キャラのQ/W/Eとパッシブ、選択したD/Fスペル。照準、発動時間、消費マナ、CD、命中、ブリンク、毒、加速・スロウ・回復・解除・シールドをサーバーで処理します。スキルボタンにマウスを重ねると現在の威力・説明を表示します。
- レベル7までの成長、XP・強化ポイント、Q/W/Eのランク強化。レベル3でランク2、レベル5でランク3を解禁します。
- ロード中・カウントダウン中の切断はマッチ無効。戦闘中は同じCookieで30秒以内に再接続すると状態を復元します。
- 戦闘中の明示退出・30秒間の片側切断は相手の勝利を通知してエントランスへ戻します。双方の切断がそれぞれ30秒続いた場合は無効試合になります。

施設は配置・衝突・視界のみ。工作員、施設への攻撃、ショップ、正式なリザルトは後続の実装です。ステップ3のブラウザー通し確認は起動環境の制約により保留しています。[実装計画と検証記録](specification/implementation-plan.md)を参照してください。

## 戦場の操作

| 操作 | 動作 |
| --- | --- |
| 地面を右クリック | 移動 |
| 視界内の敵を右クリック | 追跡して通常攻撃 |
| 左クリック | 対象情報を表示 |
| Q/W/E またはHUDのスキルボタン | 照準を開始。自己対象は即座に発動を開始 |
| 照準中の左クリック / 右クリック・Esc | 発動確定 / 照準取消 |
| Ctrl+Q/W/E またはHUDの＋ | 1ポイントでスキル強化 |
| D/F | フラッシュはカーソルへ即発動、バリアは自身に即発動、イグナイトは照準後に敵を左クリック |
| S / B | 停止 / 8秒リコール（被弾・移動で中断） |
| Y / Space | 追従切替 / 押している間だけ自分を中心に表示 |
| 矢印キー・画面端 | 自由カメラを移動 |
| ホイール / ミニマップの左クリック | ズーム / カメラ移動 |

本番配信では同一オリジンでUIを配信し、`/api/*` と `/ws` をGoへリバースプロキシしてください。WebSocketアップグレードが必要です。開発用Viteのproxy設定はビルド成果物へは含まれません。

## 検証

```sh
npm run build
npm run lint
npm run test:e2e
```

E2EはUI・Goサーバー起動済みの状態で実行します。デフォルトはインストール済みMicrosoft Edgeをheadless起動します。`BROWSER_CHANNEL=chrome` でChrome、`TEST_URL` で接続URLを変更できます。2つの独立ブラウザーコンテキストと同一セッションの追加タブで確認し、スクリーンショットは `test-results/` に保存します。

`test:e2e` は `tests/lobby.mjs`（ロビー・通常戦闘）、`tests/skills.mjs`（ソフィー・ジュード）、`tests/stage3.mjs`（ナディア・千代・スペル・成長）を順に実行します。ステップ3は実際の3キルでレベル3へ到達させるため、数分かかる場合があります。

選択画面のキャラ説明は `src/catalog.ts`、戦闘判定用の基礎能力はサーバーの `definitions.go`、スキルは `skills.go`、仕様書は `specification/`。照準とHUDにはサーバー配信のスキル定義を使用します。キャラ画像・メニュー音源は既存Auxiliaの素材を使用しています。
